# about

This is my personal design portfolio, hand-coded in ~2018 with a custom simple column grid, no framework. I'm a designer with some dev skills, so if we do make changes, explain changes in plain language. I have been called a creative technologist - because I have one foot in visual design and the other foot in front-end development, with basic to intermediate knowledge of web design technologies such as HTML, CSS and JS. My goal is to co-build and maintain this living, breathing portfolio, updating it so that its codebase is clean and professional. While doing so, I would also like to learn from you, so I can continue to learn!

# project map

- Styles live in `css/main.css`.

- Project images go in `images/<project>/`.
- Project buttons use GA4 click tracking (`gtag(...)`). Keep it when adding new project cards.
